# فصلي (Faslay) — واجهة أمامية فقط (المرحلة الأولى)

منصة تعليمية عربية، RTL بالكامل، مصممة بمنهج Mobile-First. لا يوجد أي منطق
تطبيقي — فقط واجهة React جاهزة لربطها بالمنطق والـ API لاحقًا.

> **ملاحظة مهمة:** هذا مشروع جديد منفصل تمامًا عن أي مشروع سابق (EduSpace)،
> ويستخدم امتداد ملفات **`.js`** لكل مكوّنات React (وليس `.jsx`) كما طُلب.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## ما تم بناؤه

**الصفحات** (`src/pages/`)
- `Home.js` — الرئيسية: ترحيب، عن المنصة، مدرسونا، كيف تعمل المنصة، دعوة لبدء التعلم
- `Teachers.js` — كل المدرسين (بطاقات مبسطة فقط: صورة، اسم، مادة، زر)
- `TeacherProfile.js` — ملف مدرس مبسط + قائمة "الدروس القادمة"
- `Login.js` — واجهة تسجيل دخول فقط (بريد إلكتروني، كلمة مرور، تذكرني)
- `LiveClass.js` — واجهة الفصل المباشر (شاشة رئيسية، فيديوهات مصغرة، مشاركون،
  دردشة، أزرار تحكم)

**عمدًا لم تُبنَ في هذه المرحلة:** لوحة تحكم الطالب، لوحة تحكم المدرس، أي
تسجيل/مصادقة فعلية، أي اتصال فيديو حقيقي.

**المكوّنات القابلة لإعادة الاستخدام** (`src/components/`)
`Navbar`, `Footer`, `Hero`, `AboutSection`, `TeacherCard`, `TeacherSection`,
`HowItWorks`, `CTASection`, `LessonCard`

**البيانات الوهمية**: كل شيء في `src/data/mockData.js` (مدرسون، دروس، نقاط
"عن المنصة"، خطوات "كيف تعمل المنصة") — استبدلها ببيانات الـ API لاحقًا دون
لمس أي مكوّن.

## نظام التصميم

- الألوان: أزرق فاتح وهادئ كأساس (`--color-primary: #2E90FA`) مع خلفيات فاتحة
  جدًا، ولمسة تمييز صغيرة بلون مرجاني دافئ (`--color-accent`) تُستخدم فقط في
  نقاط الحالة (مباشر الآن). كل المتغيرات في `src/styles/global.css`.
- الخطوط: **Cairo** للعناوين و **Tajawal** للنصوص — خطّان عربيّان مصممان
  للواجهات الرقمية، محمّلان عبر Google Fonts.
- العنصر المميز: خطوات "كيف تعمل المنصة" مرقمة (١، ٢، ٣) بخط رابط متقطع بينها،
  لأن المحتوى بالفعل تسلسل حقيقي (اختر المدرس ← الدروس ← الدخول للدرس).
- **RTL بالكامل**: `<html dir="rtl">`، نسخة `bootstrap.rtl.min.css`، وكل
  التخطيطات مبنية بالعربية من الأساس (وليست معكوسة لاحقًا).
- **Mobile-first**: كل الأنماط تبدأ بتصميم الموبايل ثم تُوسَّع عبر
  `@media (min-width: ...)`، وتم اختبار التخطيط ذهنيًا على أعرض من 320px حتى
  الديسكتوب دون أي تمرير أفقي.

## ملاحظة تقنية: لماذا `.js` وليس `.jsx`

Vite افتراضيًا يتوقع JSX داخل ملفات `.jsx` فقط. تم تعديل `vite.config.js`
لإجبار esbuild على معاملة كل ملفات `.js` داخل `src/` كـ JSX، حتى تعمل
المكوّنات بامتداد `.js` كما طلبت دون أي تغيير في الكود نفسه.

## ملاحظات لإضافة المنطق لاحقًا

- لا يوجد أي `useState` أو `useEffect` في أي مكان.
- زر "دخول" في `Login.js` بدون `onSubmit` منطقي — فقط `preventDefault` لمنع
  إعادة تحميل الصفحة.
- رسائل الخطأ في `Login.js` جاهزة كـ CSS (`.login-field--invalid`) لكنها غير
  مفعّلة — فعّلها بإضافة الـ className ديناميكيًا حسب حالة التحقق الخاصة بك.
- كل أزرار التحكم في `LiveClass.js` (ميكروفون، كاميرا، مشاركة شاشة، مغادرة)
  بدون `onClick` — أضف منطقك مباشرة.
